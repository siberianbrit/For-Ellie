# Ellie — Pet Care (Supabase)

Это версия приложения для собак с **общей облачной базой Supabase**.

## 1. Создайте НОВЫЙ Supabase project

Откройте Supabase Dashboard и создайте отдельный проект именно для Ellie.

После создания вам нужны:
- Project URL
- Publishable key

Они находятся в Connect / API settings вашего проекта.

**Важно:** в GitHub/браузер можно помещать только Publishable key. Никогда не вставляйте `service_role` key в `config.js`.

## 2. Создайте базу

Откройте **SQL Editor** вашего нового проекта.

Откройте файл `supabase.sql`, скопируйте весь текст и нажмите Run.

Он создаст:
- dogs
- medications
- medication_logs
- vaccinations
- vet_visits
- heat_cycles
- weights

и включит RLS-политики, чтобы пользователь видел только свои данные.

## 3. Подключите приложение

Откройте `config.js` и замените:

window.SUPABASE_URL = "https://YOUR-PROJECT-REF.supabase.co";
window.SUPABASE_PUBLISHABLE_KEY = "YOUR_SUPABASE_PUBLISHABLE_KEY";

на данные нового проекта.

## 4. GitHub

Загрузите ВСЕ файлы прямо в корень repository:

index.html
config.js
supabase.sql
manifest.json
sw.js
icon.svg
README.md

Папка `assets` не нужна. Фото Ellie встроено непосредственно в index.html.

После этого:
Settings → Pages → Deploy from a branch → main → / (root)

## 5. Первый запуск

Откройте GitHub Pages ссылку.

1. Создайте аккаунт.
2. Войдите.
3. Приложение автоматически создаст Ellie и первоначальную историю из вашего текущего трекера.
4. После этого данные будут храниться в Supabase и синхронизироваться между устройствами при входе в тот же аккаунт.

На этом этапе приложение показывает следующую дату и календарные события. Настоящие системные push-уведомления iPhone — отдельный следующий этап; для них нужно добавить Web Push/notifications и service-worker logic.
